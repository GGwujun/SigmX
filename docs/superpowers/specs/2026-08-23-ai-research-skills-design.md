# SigmX AI 投研技能库设计

## 目标

新增一个面向 Web 用户的“投研 Skills”产品入口，把 Data Hub 的数据能力封装成可安装到本地 AI 智能体的投研方法。首版为前端产品原型，重点验证发现、安装、配置 Credential 与使用 Data Hub 的商业闭环，不开放社区发布，也不实现服务端执行。

## 产品定位

- **Data Hub** 是数据层：提供行情、财务、资金、公告、行业与宏观数据。
- **投研 Skills** 是方法层：安装到 Codex、Claude Code、OpenClaw 或 SigmX Desktop，定义输入、分析步骤、数据依赖与标准输出。
- **AI 发现** 是在线体验层：帮助用户理解 Skill 能力并体验简化研究流程。
- **Desktop** 是深度工作层：承接持续跟踪、复杂研究和自动化执行。

顶部导航名称使用“投研 Skills”，广场页面标题使用“AI 投研技能库”。公开路由为 `/skills`，详情路由为 `/skills/:slug`。

## 首版范围

### 技能广场

广场提供：

- 关键词搜索。
- 场景分类：全部、选股筛选、公司研究、财务分析、事件公告、资金情绪、行业宏观、ETF 基金、风险管理。
- 官方精选区，突出可信、可直接运行和数据可追溯。
- 技能卡片，展示名称、用途、官方认证、标签、使用次数、更新时间、数据来源数量与预计信用消耗。
- 不展示社区上传、作者结算或评分评论；提供安装命令与 Skill 文件预览。

### 技能详情

详情页展示：

- Skill 的问题定义与适用场景。
- 示例问题与可编辑输入。
- 分析步骤和标准输出。
- 使用的 Data Hub 数据集及接口。
- Research Credit 与 Data Credit 预计消耗。
- 数据更新时间、风险说明与结果示例。
- “安装到本地智能体”和“申请 Data Hub Credential”两个主要动作。
- Codex、Claude Code、OpenClaw 与 SigmX Desktop 安装方式切换。

### 安装与使用衔接

详情页默认展示 Codex 安装方式，用户可切换本地智能体。安装区提供：

- 可复制的安装命令。
- `SKILL.md` 文件内容预览。
- Data Hub Credential 环境变量配置示例。
- 所需 Data Hub 接口与预计 Data Credit。

“在线体验”作为次要动作跳转到 `/?skill=<slug>&q=<question>`；“在 Desktop 使用”跳转到 `/product/desktop`。

## 首批技能

首版提供 12 个官方技能：

1. 低估值高股息筛选
2. 财务质量与造假风险扫描
3. 盈利拐点识别
4. 公司公告影响分析
5. 机构调研与预期变化
6. 主力资金异动追踪
7. 行业景气度比较
8. ETF 流动性与折溢价分析
9. 财报三表深度解读
10. 估值区间与敏感性分析
11. 事件驱动机会扫描
12. 投资组合风险体检

每个 Skill 使用统一的数据结构，包含 slug、名称、描述、分类、标签、数据集、分析步骤、示例问题、输出、使用量、更新时间和信用消耗。

## 页面结构

### `/skills`

1. 紧凑型产品标题区，说明“Data Hub 提供数据，Skills 提供方法”。
2. 搜索框与分类筛选。
3. 官方精选横向区域，突出 3 个核心 Skill。
4. 全部技能响应式卡片网格。
5. Data Hub 与 Desktop 的产品关系说明。

页面沿用现有 SigmX Web 的浅色、紧凑金融工作台语言，不复制参考站点的品牌、文案和视觉资产。

### `/skills/:slug`

1. 返回广场与 Skill 基本信息。
2. 左侧主要内容：适用场景、分析流程、输出样例、Skill 文件预览。
3. 右侧固定安装卡：智能体选择、安装命令、Credential 配置、信用消耗和主要动作。
4. Data Hub 数据依赖列表，每项链接到 `/docs/data-hub/`。

## 状态与数据流

Skill 数据首版存放在前端静态模块，广场和详情共用同一来源。

1. 广场根据搜索词和分类过滤 Skills。
2. 点击卡片进入详情路由。
3. 详情页选择本地智能体并复制安装命令。
4. 用户配置 Data Hub Credential，本地智能体运行 Skill 时调用 SigmX Data Hub。
5. 在线体验从 URL 读取 `skill` 和 `q`，复用 AI 发现研究链路。

未知 slug 显示友好空状态并提供返回广场入口。搜索无结果时保留当前筛选条件并提供清除筛选动作。

## 组件边界

- `researchSkillsData.ts`：Skill 类型、分类和演示数据。
- `ResearchSkillsPage.tsx`：广场搜索、分类与卡片列表。
- `ResearchSkillDetailPage.tsx`：详情与运行入口。
- `LandingPage.tsx`：只负责读取 Skill 参数并把元数据传入现有研究流程。
- `PublicLayout.tsx`：增加“投研 Skills”导航。
- 两套路由注册 `/skills` 和 `/skills/:slug`。

## 可访问性与响应式

- 搜索框有明确标签。
- 分类使用可识别的按钮与 `aria-pressed`。
- Skill 卡片使用语义链接。
- 主要动作具有唯一可访问名称。
- 移动端由双栏详情退化为单栏，运行卡不固定。

## 测试

- 导航测试：顶部“投研 Skills”指向 `/skills`。
- 广场测试：渲染 12 个 Skill、分类筛选、搜索与空状态。
- 详情测试：正常 Skill、未知 slug、Data Hub 依赖链接。
- 衔接测试：智能体切换生成正确安装命令，Credential 入口与 Data Hub 文档可达；在线体验生成正确的 AI 发现 URL。
- 回归验证：完整 Vitest、TypeScript 检查和 Vite 生产构建。

## 非目标

- 不执行真实的第三方安装命令；只生成可复制命令与文件。
- 不实现社区作者、上传审核、评论评分或收益分成。
- 不新增后端数据库或真实 Skill 执行服务。
- 不改变 Data Hub 计费规则。
