# SigmX Web 运行时去 Mock 与真实服务化设计

## 目标

SigmX Web 的所有业务页面只展示真实服务返回的数据。服务无数据时展示空状态，服务失败时展示错误与重试，不允许回退到静态候选、演示行情、伪进度或预制研究结论。

测试夹具和单元测试 mock 不在删除范围内；产品介绍中的能力说明、导航配置和接口文档元数据也不属于业务 mock。

## 当前状态

已有真实能力包括认证、账户、套餐与订单、Research/Data Credit、设备、Data Hub Credential 与用量、云端查询与自选、研究交接、部分运营指标，以及 `/api/v1/*` 金融数据接口。

主要运行时假数据位于：

- AI 发现首页的市场脉搏、模板执行过程、候选结果和研究摘要。
- 独立研究结果页的指标、证据、结论和风险。
- 情报搜索的筛选计数、情报列表、详情和投资影响。
- Skills 广场及详情页的技能目录、版本、安装内容和统计。
- 示例报告的静态报告正文。
- 运营后台占位模块的用户、内容、审计和系统统计。

## 方案选择

采用“领域服务 + 纵向链路逐批替换”。不采用逐组件临时补接口，因为会产生重复模型和不一致错误处理；不采用一次性大爆炸替换，因为无法持续验证数据真实性。

## 后端领域

### 1. 市场发现

提供最新交易日、指数概览、市场宽度、成交额和研究模板接口。市场数据复用现有 Data Hub 查询层，响应必须包含 `as_of`、`source`、`is_delayed` 和质量状态。

### 2. 研究任务

新增研究任务与结果存储：

- `research_tasks`: 用户、问题、模板、范围、状态、步骤、错误、创建和完成时间。
- `research_results`: 任务、摘要、筛选条件、候选、证据、风险、数据口径与版本。
- `research_evidence`: 数据域、来源、时间、引用标识、原始值和解释。

API 支持创建任务、查询状态、取消、读取结果。执行器从 Data Hub 获取真实数据，LLM 只负责解释和组织，不允许凭空补齐缺失指标。首版使用现有后台任务机制；状态持久化，页面刷新后仍可恢复。

### 3. 情报

将新闻、公告和行业事件统一为情报记录，字段包含来源 URL、发布时间、抓取时间、分类、实体、摘要、事实、影响和质量状态。搜索与分类计数由服务端计算；详情必须能打开原始来源。情报转研究通过研究任务 API 创建任务。

### 4. Skills

建立服务端技能注册表，保存 slug、名称、版本、分类、维护方、描述、所需 Data Hub 接口、安装模板、风险说明和发布状态。广场和详情页读取注册表；安装次数与运行记录来自真实事件。CLI/Agent 安装文本由服务端模板生成，不在前端硬编码凭据。

### 5. 运营后台

各模块使用独立 API：用户、订单与套餐、Data Hub、内容、客服、审计、系统。未实现的模块显示“尚未配置”或空状态，绝不显示占位数字或虚构用户。

## 前端契约

每个服务页面统一四态：`loading`、`ready`、`empty`、`error`。页面不得导入运行时业务数据文件；模板与技能等可配置内容也由 API 返回。请求失败不得使用本地静态数组兜底。

研究运行链路为：提交问题 → 返回任务 ID → 轮询/事件更新步骤 → 完成后读取结果 → 结果页按证据渲染。进度只展示服务端已确认的步骤，不使用定时器模拟百分比。

## 数据真实性与安全

- 所有市场、新闻和研究结果携带来源与时间。
- 研究任务需要登录；公开市场摘要和已发布 Skills 可匿名读取。
- 运营 API 强制管理员权限并写审计日志。
- API Key、Credential 和安装密钥不进入前端静态文件或日志。
- 外部数据源不可用时返回明确的降级状态，但不返回伪造数据。

## 迁移顺序

1. 建立公共响应模型、错误模型和运行时 mock 扫描器。
2. 市场概览与研究模板服务化。
3. 研究任务、执行器、证据和完整结果服务化。
4. 情报搜索、详情与转研究服务化。
5. Skills 注册表、详情、安装模板和事件服务化。
6. 运营后台占位模块服务化或改为空状态。
7. 示例报告改为真实发布报告；删除静态样本路由或改为服务端内容。
8. 删除所有运行时业务数据文件与演示分支，执行全站验收。

## 测试与验收

- 后端：领域单元测试、API 权限测试、任务状态迁移、来源字段和错误路径测试。
- 前端：契约测试、加载/空/错/成功四态、刷新恢复和跨页任务结果测试。
- 集成：使用本地真实数据库和数据源运行 AI 发现、情报、Skills、个人中心、运营后台链路。
- 静态门禁：生产源码出现 `演示数据`、预制候选/新闻/技能/运营统计或页面级业务数组时失败；测试目录除外。
- 断源验收：关闭外部数据源后页面必须显示不可用状态，不得出现看似真实的结果。

## 完成定义

所有 Web 业务页面的可变业务内容均可追溯到真实 API；运行时不存在静态业务结果、模拟进度或演示回退；全站成功、空数据、服务失败和权限路径均已验证。
